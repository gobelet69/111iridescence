# Product asset provenance

These assets are copied from the application sources; they are not generated product mockups.

- `iridescence-pdf-reader/icon.png`: converted from `AppIcon.icns` in the private `gobelet69/iridecence-pdf-reader` checkout.
- `iridescence-pdf-reader/*.png`: approved screenshots from `docs/screenshots/` in that checkout. Home-screen captures were intentionally excluded because they contain local personal paths.
- `mass-print/icon.png`: `src-tauri/icons/icon.png` from public release source `gobelet69/Mass-Print` v0.1.3.
- `mass-print/mass-print-main.png`: the real v0.1.3 frontend rendered with a representative local queue through the official Tauri mock boundary.
- `*/og.png`: resized copies of each app’s authentic primary capture.
