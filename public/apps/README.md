# Product asset provenance

These assets are copied from the application sources; they are not generated product mockups.

- `iridescence-pdf-reader/icon.png`: converted from `AppIcon.icns` in the private `gobelet69/iridecence-pdf-reader` checkout.
- `iridescence-pdf-reader/*.png`: approved screenshots from `docs/screenshots/` in that checkout. Home-screen captures were intentionally excluded because they contain local personal paths.
- `mass-print/icon.png`: `src-tauri/icons/icon.png` from public release source `gobelet69/Mass-Print` v0.1.3.
- `mass-print/mass-print-main.png`: native SwiftUI development preview captured on 2026-11-17 from the Mass Print working tree based on ff0f7e2, including the UI/keyboard improvements under review. Uses the actual ContentView and Rust engine with four synthetic text documents and an injected Office Printer; no print job was submitted. This is a view-cache capture, not a compositor screenshot or a published-release claim. Visible captions distinguish the development preview from the downloaded public release. Private capture/build evidence remains in the ecosystem audit workspace.
- `quickpad/icon.png`: converted from `AppIcon.icns` in `gobelet69/quickpad` v1.0.0.
- `quickpad/*.png`: split-view Markdown and JSON Tree Inspector captures from `QuickPad` v1.0.0.
- `*/og.png`: resized copies of each app’s authentic primary capture.
