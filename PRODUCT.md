# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

macOS power users, creative professionals, engineers, and minimalist Mac enthusiasts seeking fast, focused, private desktop utilities without subscriptions, telemetry, or web wrappers.

## Product Purpose

111iridescence is an independent macOS software studio showcase and distribution site. It presents native tools engineered with Swift, Rust, and AppKit for speed, privacy, low resource footprint, and local-first workflows.

## Positioning

Pure native macOS utilities crafted with low-level systems languages (Rust & Swift 6) that prioritize instant responsiveness, zero telemetry, and true macOS ergonomics, standing apart from bloated Electron wrappers and cloud-gated subscription software.

## Operating Context

Desktop and mobile web visitors exploring macOS software, evaluating feature depth, verifying release provenance (GitHub releases, SHA-256 checksums), and downloading notarized Mac applications.

## Capabilities and Constraints

- Static site generated with Astro 5/7, TypeScript, and custom CSS design tokens.
- Dual-language support: English as primary (`/`) and French under `/fr/`.
- Zero third-party telemetry, trackers, or external CDN dependencies.
- Interactive canvas: Signature animated pixelated "111iridescence." hero with interactive optical signal.
- Showcases three flagship native applications:
  1. Iridescence PDF Reader (v0.8.2) — Dual-sidebar fast document reader with outline navigation.
  2. Mass Print (v0.8.2) — Batch printing utility with document ordering and print safety controls.
  3. Resource Guard (v0.8.2) — Menu bar & window resource monitor with low-overhead metrics.
- Absolute privacy constraint: Never disclose the creator's real first or last name, personal paths, or credentials.
- AI transparency: Maintain clear, authentic disclosure of AI-assisted development.

## Brand Commitments

- Studio Identity: 111iridescence
- Visual Concept: "The Prismatic Atelier" — Architectural clarity, luminous pearl canvas (`#FAF9FC`), obsidian ink (`#16101D`), specular crystal glass panels, and disciplined spectral color accents.
- Voice: Independent atelier, meticulous, restrained, technically literate, and honest.

## Evidence on Hand

- Three functional native macOS applications with notarized binaries and verifiable GitHub releases.
- Authentic high-resolution application screenshots in both light and dark native macOS appearances.
- Clean E2E test suites and accessibility test coverage.

## Product Principles

1. **Native Mac Craft**: Deep fidelity to Apple interface guidelines, typography, and keyboard affordances.
2. **Local-First & Private**: No analytics, no tracking, complete respect for user data sovereignty.
3. **Restrained Iridescence**: Optical refraction, specular caustics, and subtle spectral rim lighting rather than decorative rainbow gradients.
4. **Verifiable Truth**: Every screenshot, download link, checksum, and feature claim reflects real running software.

## Accessibility & Inclusion

Full WCAG AA adherence: semantic HTML5 landmarks, 4.5:1+ text contrast, focus indicators, keyboard traversal, and strict `prefers-reduced-motion` compliance.
